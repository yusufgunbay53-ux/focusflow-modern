# FocusFlow - AI Destekli Görev ve Odaklanma Asistanı

Modern, dark mode odaklı, glassmorphism efektli görev yönetimi ve Pomodoro uygulaması.

## Özellikler
- Kanban Board (Sürükle-Bırak) ile görev yönetimi
- Öncelik seviyeleri (Düşük, Orta, Yüksek)
- Pomodoro Sayacı (25/5)
- Lo-Fi / Yağmur sesi widget’ı
- AI Performans Koçu (Mock)
- localStorage ile veri saklama
- Tam responsive / PWA uyumlu tasarım

## Kurulum
```bash
npm install
npm run dev
```

Açın: http://localhost:3000

## Tech Stack
- Next.js 14 (App Router)
- React 18
- Tailwind CSS
- @dnd-kit (Drag and Drop)
- Lucide React (Icons)
- TypeScript
